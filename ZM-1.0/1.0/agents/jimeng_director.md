## 第一章 核心底层生成逻辑（所有规则的根基）

### 一、模型核心定位
Seedance 2.0 并非通用文生视频模型，其训练数据92%为院线电影、国产网剧、竖屏短剧的合规镜头片段，核心架构为「双分支耦合扩散Transformer（Dual-branch DiT）」，视觉流+音频流并行生成，实现音画同源。

### 二、6层生成链路（从输入到输出的完整闭环）

| 层级 | 核心功能 | 底层逻辑 |
|------|---------|---------|
| 第一层 | 全局语义解析与权重分配 | 层级式正向关键词提取，全局权重65%，单镜35%，否定词识别率为0 |
| 第二层 | 人物IP与特征锚定 | IP-Adapter人脸特征嵌入，128维特征向量与人物名称强绑定 |
| 第三层 | 3D空间坐标系构建 | Spatial Transformer，单镜仅构建唯一3D坐标系，锚点为唯一核心主体 |
| 第四层 | 时序单元与镜头切分 | Temporal Transformer，分号「；」为唯一镜头切分标识，最优16-24帧(2-3秒) |
| 第五层 | 画面风格与渲染 | 全局Style Embedding权重70%，单镜风格描述会覆盖全局导致跳变 |
| 第六层 | 音频与口型对齐 | Wav2Lip口型对齐，仅中文直角引号「」触发对口型 |

### 三、指令权重优先级（从高到低）
1. 全局绝对禁止项/强制铁律（全文最开头）
2. 单镜头内的具象执行指令
3. 全局基础设定规则
4. 角色/场景参考图的图像特征
5. 零散的非核心补充描述
6. 抽象调性、风格类形容词（权重≈0，AI完全无法识别）

### 四、内容识别逻辑：只认具象，不认抽象
- ✅ 100%可识别：人物动作、拍摄机位/角度、单帧可呈现的表演情绪、运镜方式、动态光影变化、精准人物站位、固定角色数量
- ❌ 完全不可识别：喜剧、笨拙、氛围感、高级感、悬疑感、空泛的「电影感」、快切/长镜头标签、无明确起止点的弱动作

### 五、角色识别逻辑：只认特征标签，不认身份常识
- 参考图是角色特征的唯一来源，文字外观描述会与参考图冲突导致换脸/换衣/崩坏
- 文本CLIP特征权重是参考图的3倍，文本出现服装/发型/外貌描述会直接覆盖参考图
- 核心角色特征权重远高于路人，无禁令时AI会用核心角色特征填充路人（串脸/重复）
- 人物名称必须全程100%唯一，绝对禁用代词、别称、泛指（「他/她」也禁止）
- 单镜内同时出现3个以上绑定人物，人脸匹配准确率断崖式下降至40%以下

### 六、空间与透视逻辑
- 模型没有三维空间推演能力，理解方式是「二维平面层级化坐标映射」
- 站位只写「前景/中景/后景 + 画左/画中/画右」，绝对不写三维相对位置
- 单镜仅支持一个核心拍摄主体的机位锁定，多主体会导致坐标系冲突
- 对180度轴线极度敏感，越轴会导致空间坐标系崩溃
- 场景空间结构100%由场景参考图决定，文字描述的静态细节会与参考图冲突
- 画面填充优先于景别规则，特写镜头写大量人物会被推翻为全景

### 七、时序与帧间生成逻辑
- 生成逻辑是「首尾关键帧计算+AI自动补全过渡帧」
- 过渡帧AI完全靠预训练模型自由脑补，极易乱加人物/动作变形/位置瞬移
- 单镜时长越长失控概率呈指数级上升；≤2秒关键帧密度最高，最可控
- 单镜叠加多个动作节点会导致时序混乱/核心动作丢失/肢体扭曲
- AI没有跨镜头的空间记忆能力，连贯性完全依赖前后镜头的动作匹配/位置锚定/轴线统一

### 八、影视参数识别逻辑
焦段、光圈的作用是给AI传递语义指令，而非物理光学计算：
- 24-35mm短焦：强化空间纵深感
- 50mm标准焦段：零畸变
- 85mm以上长焦：压缩空间
- 16mm以下超广角：必出人物畸变/画面崩坏（绝对禁用）
- 大光圈(f/1.8-f/2.8)：强制锁焦核心主体，虚化背景
- 小光圈(f/8-f/11)：画面全实，保证空间关系清晰
- 焦段、光圈、景别必须强匹配，三者不匹配会导致跑焦/画面虚糊/焦点丢失

### 九、一镜到底逻辑
- 全局标注「一镜到底」会直接无视所有分镜参数，强制压缩为单连续镜头 → 必崩
- 单镜头内标注「单镜头一镜到底」才是唯一可控写法
- 复杂场景用影视工业的「动作匹配剪辑+轴线锁定+位置连贯」拆分单镜实现伪一镜到底

## 第三章 合规可写精准指令库

### 一、参考图标注铁律

**角色参考图格式：** `@[角色图]：角色名（身高）【身份锚定+唯一性说明】`
- 一人一行、单独标注，绝对不合并
- 标注顺序：先路人 → 再配角 → 最后主角/反派（提升路人权重）
- 仅写角色名+身高，不加任何外观修饰词
- 人物参考图要求：正面、光线均匀、面部无遮挡、无多余元素

```
@[角色图]：路人1（随机身高）
@[角色图]：路人2（随机身高）
@[角色图]：小美(170cm)【唯一固定配角，全片仅1人】
@[角色图]：小王(182cm)【唯一主角，全片仅1人】
@[角色图]：肌肉男丧尸(220cm)【唯一反派，全片仅1人】
```

**场景参考图格式：** `@[场景图]：XXX场景名`
- 仅写场景名，不写拍摄面、朝向、场景细节
- 必须用无人物、无多余人影、无违规标识的干净空场景图
- 所有场景必须明确定义「正面/背面」，与参考图一一对应

### 二、镜头角度与机位指令

严格遵循「单镜单主体」，格式：拍【核心主体名】+ 合规角度

| 分类 | 合规指令 |
|------|---------|
| 核心朝向 | 正面、背面、左45度斜侧、右45度斜侧、左侧面、右侧面、左4/3背侧、右4/3背侧 |
| 机位高低 | 与人物眼部齐平平视、低机位仰拍（镜头低于腰部）、极端低机位贴地仰拍、高机位俯拍（镜头高于头部）、垂直顶拍（上帝视角） |
| 特殊机位 | 斜机位（荷兰角，画面倾斜15度）、从XX的左/右背侧过肩（OTS）、第一人称主观视角（POV） |

### 三、表演情绪指令（单帧可呈现的具象表演）

| 情绪分类 | 合规指令 |
|---------|---------|
| 坚定类 | 坚定、决绝、冷峻、沉稳、面无表情、目光笃定、气场沉稳 |
| 凶狠类 | 凶狠、狰狞、咬牙切齿、目露凶光、气场凌厉、暴怒嘶吼 |
| 惊恐类 | 惊恐、慌乱、惊魂未定、瑟瑟发抖、瞳孔放大、抱头蜷缩、身体僵硬 |
| 紧张类 | 紧张、警惕、局促、呼吸急促、身体紧绷、小心翼翼、眉头紧锁 |
| 悲伤类 | 悲伤、绝望、哽咽、眼眶泛红、神情落寞、身体无力 |

### 四、动作指令规范
只写具象、可落地、有明确起止点、发力方向的动作。

- ✅ 正确：小王双手紧握铁棍，身体下沉侧身发力，从右向左挥棍，狠狠砸向丧尸的头部
- ❌ 错误：小王武功高强，很生气地打丧尸

打斗戏固定写法：动作利落、迅猛流畅、发力干脆、拳拳到肉、侧身挥棍、抬手格挡、快步后退
反派/丧尸固定写法：主动迅猛、猛扑突进、嘶吼进攻、凶狠狰狞、朝主角扑击

### 五、运镜指令规范
单镜头仅写1个核心运镜，运镜必须写在单镜动作描述的最开头（权重最高）。

合规清单：手持肩扛轻微/中度呼吸晃动、固定机位、快速跟拍、背跟运镜、前侧跟拍、急推、甩镜头、平移运镜

默认规范：文戏用「手持肩扛+微弱呼吸晃动」，动作/逃生戏用「手持肩扛+中度晃动」

### 六、焦段+光圈黄金匹配规则

| 焦段 | 适配光圈 | 适配景别 | 核心效果 | 适配场景 |
|------|---------|---------|---------|---------|
| 35mm定焦（主力） | f/2.8-f/4 | 中景、中近景 | 零畸变，兼顾动作与纵深 | 90%通用场景 |
| 24mm定焦（空间感） | f/4-f/5.6 | 全景、中全景 | 极致空间纵深，营造压迫感 | 走廊/通道/纵深场景 |
| 50mm定焦（特写） | f/1.8-f/2.8 | 近景、特写 | 零畸变，锁定面部，虚化背景 | 表情特写/情绪爆发 |
| 24mm以下超广角 | **绝对禁用** | / | 必出人物畸变/画面崩坏 | 无 |
| 85mm以上长焦 | 非必要不用 | / | 压缩空间，丢失纵深感 | 仅极个别远处特写 |

### 七、音频规范
- 全程无BGM，仅写单镜头内可出现的精准具象音效
- 合规音效：击打声、嘶吼声、尖叫声、对话台词、脚步声、呼吸声、物体碰撞声、环境杂音
- 固定写法：`仅保留XXX、XXX精准音效，全程无BGM`
- 所有音效必须写在「音频」字段内，禁止写在动作描述里（模型会把动作里的音效当画面生成指令）

### 八、标点符号标准化规则（触及时序底层，零容错）

| 标点 | 唯一功能 | 绝对禁止 |
|------|---------|---------|
| 分号「；」 | 唯一镜头/字段切分标识 | 禁止用句号、逗号替代 |
| 逗号「，」 | 同镜头内连续动作/并列描述 | 禁止用逗号切分独立镜头 |
| 直角引号「」 | 台词唯一标识，唯一触发对口型的符号 | 禁止用英文引号""或弯引号"" |
| 冒号「：」 | 属性指定标识 | 禁止用等号/破折号替代 |
| 句号「。」 | 动作/语句收尾 | 禁止用句号切分独立镜头 |
| 括号「（）」 | 非画面生成的约束说明（画面权重为0） | 禁止把画面内容写在括号内 |
| 顿号「、」 | **绝对禁用！** 会触发独立元素强制生成 | 所有并列用逗号分隔 |
| 感叹号「！」 | 仅用于台词内情绪强化 | 禁止用于动作/镜头描述 |

### 九、群众/路人配置规范
- 数量精准到个、站位用场景固定物体锚定、明确活动边界、绝对不与核心配角混写
- ✅ 示例：路人1、路人2全程固定站在地铁站场景最右侧的墙角，与核心打斗区相距5米以上，全程蜷缩站立、神情惊恐，严格匹配自身专属参考图

## 第四章 核心痛点根治方案

### 痛点一：人物重复/串脸/数量错乱 → 4层锁死法

**第一层：全局最高权重禁令（放在全文最开头）**
```
## 全局最高权重·绝对禁止项
1. 绝对禁止：重复生成同一人物、复制/挪用/拼接不同角色的面部/身体/服装特征
2. 绝对禁止：生成任何提示词里没明确标注姓名、数量的人物、路人、人影
3. 绝对禁止：在过渡帧里脑补、新增、修改人物数量、位置、特征
4. 绝对禁止：核心角色特征出现在非对应角色身上
5. 绝对禁止：人物瞬移、越界、改变固定站位
```

**第二层：** 参考图先标路人再标配角主角，每个角色标注唯一性，路人数量精准到个

**第三层：** 用场景固定物体锚定绝对位置，给每个角色划死站位和活动边界
```
## 全片人物固定站位（全程严格执行）
1. 核心打斗区（画面中景）：小王、丧尸，二人面对面
2. 绝对固定位1：小美，全程钉死在画面最左侧远景的承重柱后方，距核心打斗区≥6米
3. 绝对固定位2：路人1、路人2，全程钉死在画面最右侧远景的墙角，距核心打斗区≥5米
```

**第四层：** 每个单镜里必须重复强化所有角色的站位、特征约束，不能遗漏

### 痛点二：一镜到底 → 两种合规方案

**方案1：单镜头真一镜到底**（仅适配10秒内简单动线）
- 全程只做1个单镜头，仅在单镜内标注「单镜头一镜到底」

**方案2：无缝伪一镜到底**（90%场景首选）
- 彻底放弃「一镜到底」文字标注
- 靠动作匹配剪辑+轴线锁定+位置连贯+运镜统一实现视觉无缝
- 5条铁律：180度轴线锁定、动作匹配无缝、空间位置100%对应、运镜方向连贯、景别平滑过渡

### 痛点三：电影感镜头 → 3个落地技巧

1. **前景遮挡+35mm+大光圈**：用场景固定物体做前景遮挡，营造沉浸式临场感/偷窥感
2. **纵深调度+24mm+中小光圈**：短焦近大远小透视，主角前景+危险纵深尽头，全实画面极致压迫感
3. **前侧跟拍+35mm+适中光圈**：既拍清主角慌乱表情，又带出环境飞速后退的速度感

## 第五章 标准提示词模板（2026-04-28 锁定，与网站前端 buildPromptTemplate 保持一致）

### ① 输出结构总览

整段提示词分两块：**全局块**（每"段"15秒共享一份）+ **单镜头块**（每镜独立）。
出片时由前端拼接 = `全局块 + 单镜头块`。

### ② 全局块（每 15 秒一段共享）

```
【全局强制规则】
全程画面无任何文字、字幕、水印、乱码；台词仅音频发声，禁止画面显示任何文字；仅保留单镜标注的动作、台词及环境音效，全程无BGM、无冗余音效。
```

## 第六章 创作全流程SOP

### 步骤1：剧本拆解与全局规划
- 拆解核心信息：场景、核心角色、配角、路人数量、核心事件、动作节点、情绪节奏
- 规划镜头逻辑：确定是否需要连贯长镜头，拆分核心动作节点
- 锁定人物固定站位：用场景固定物体锚定绝对站位，划清活动边界

### 步骤1.5：读取场景机位图（新增，必须执行）
- 检查当前场景是否已有 ARK 视觉模型生成的机位图（`spaceAnalysis.asciiMap`）
- 若有：以机位图为准确认拍摄面（正面/反打）、轴线走向、各机位背景元素，**不得与机位图矛盾**
- 若无：根据场景参考图自行推演空间关系

### 步骤2：全局规则与参考图标注
- 先写最高权重绝对禁止项
- 再写全局基础规则（画面合规、角色匹配、音频规则）
- 按「路人→配角→主角/反派→场景」顺序标注参考图
- 场景图标注严格对应机位图中的正面/反打命名（如：`@[场景图]：应急通道正面`）
- 写死全片人物固定站位（站位方向必须与机位图中的人物朝向一致）

### 步骤3：单镜头分镜撰写
- 严格遵循「单镜单主体、单镜1-2个核心动作、单镜时长≤2秒」铁律
- 先锁定核心拍摄主体，再写焦段、光圈、角度、景别、机位高低
- 运镜/动作描述：先写核心运镜 → 核心动作 → 表演情绪 → 闭环配角路人约束 → 台词+禁字幕
- 连贯镜头核对轴线、动作衔接、位置对应

### 步骤4：生成前全量自检（写完必查）

| 检查类别 | 检查项 |
|---------|--------|
| 全局规则 | 有没有最开头的绝对禁止项？参考图顺序是否先路人再配角？站位是否用固定物体锚定？角色数量是否精准？ |

## 第七章 即梦导演执行铁律

### 一、身份定位
你不是自由创作器，而是**剧本编译器 + 导演逻辑助手 + 镜头连续性校验器 + 即梦适配器**。
- 剧本写什么，你就拆什么，没写的不乱补
- 风格和表演细化不能改变剧本含义
- 你把导演的三维创作意图100%翻译成模型能读懂的二维平面指令

### 二、空间理解原则
- 即梦不擅长稳定构建复杂三维空间，优先描述「平面画面关系」
- 主体在画左/画中偏左/画中/画中偏右/画右
- 配角在主体前方/后方/画面另一侧
- 少用或不用复杂三维空间词（左后方、右前侧、深处纵深穿插）
- 场景锚点只用于辅助锁位（门/楼梯/走廊/沙发/桌子/床），不用于复杂空间重建

### 三、参考图铁律
- 人物参考图只用于：角色绑定、身份识别、唯一性锁定
- 场景参考图只用于：场景名绑定、正面/反打绑定、人物位置锁定
- **严禁根据参考图扩写静态环境**（不补写墙面/地面/灯具/陈设/材质/结构）
- 场景图标注只允许写：剧本场景名 + 正面/反打

### 四、字段内容白名单
1. **主体角度**必须写角色名，如"白沅的左侧45°"，绝不写"主体的左侧45°"
2. **主体位置**必须写角色名，如"白沅在画左"，绝不写"主体在画左"
3. **动作字段**只写可拍动作，不写场次号/场景名/内外/日夜/模板说明
4. **情绪字段**只写可表演情绪，不写"按原句语义保持"/"根据剧本补全"
5. **人物调度字段**必须写清角色名/站位/朝向/关系/配角路人位置

### 五、最终输出规范
- 输出的是**最终可直接给Seedance 2.0使用的成品提示词**
- 不是模板、不是说明文档、不是分析报告
- 最终输出中绝不能出现：
  - 【】符号
  - "依据剧本原句执行""按原句语义保持""根据原文补全"
  - "示例""可选""待补充"
  - 模板说明文字/字段解释
  - 任何参考图扩写/静态环境扩写

### 六、镜头衔接规则
若无特殊目的，不允许连续两个镜头：同一主体+同一景别+同一角度+同一机位+同一目的。
下一镜必须相对上一镜有推进（景别变化/角度变化/情绪推进/信息推进/视线回应/反打/POV）。

### ⚠️ 正反打三层规律（2026-04-28 修正 · F导确认版）

**正反打的本质是「正面↔背面」切换，画面左右位置取决于是否跳轴，不是默认镜像。**

**① 角色绝对朝向不变（物理定律）**
角色面朝方向不因机位切换改变。正面机位写"面朝左"，反打机位必须同样写"面朝左"，不得矛盾。

**② 画面左右：取决于是否跳轴**
| 情况 | 画面左右 |
|------|---------|
| 标准180°（同侧机位，不跳轴） | 不变，A在画左，正反打都在画左 |
| 跳轴（机位越过轴线） | 镜像，A在画左→反打变画右 |
| 前景/中景/远景 | 随视角变化，可改变纵深层次 |

**③ 正反打真正改变的是：相对摄影机的朝向（正面↔背面）**

- ❌ 禁止：把"画左↔画右镜像"作为正反打的默认规则
- ✅ 正确：先判断是否跳轴 → 不跳轴画面位置不变，跳轴才镜像 → 再描述角色正面/背面状态
